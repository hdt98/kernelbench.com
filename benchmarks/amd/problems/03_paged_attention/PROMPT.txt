I need you to write a paged attention decode kernel for the AMD Instinct MI325X (gfx942, CDNA 3, 288 GB HBM3E at 8.0 TB/s). The reference implementation is in reference.py and your kernel goes in solution.py. You can make whatever mess you want in this directory — scratch files, intermediate kernels, build artifacts, profiling traces — but the final answer has to be in solution.py with the same Model, get_inputs, and get_init_inputs interface as reference.py.

This is single-query decode: each batch element has a query of shape (num_heads, head_dim) and attends over a KV cache of seq_len[b] tokens stored as fixed-size pages in a global pool. Pages for batch element b are listed in block_table[b]. The KV cache packs [K | V] in the last dim so a single gather pulls both. GQA (grouped-query attention) is supported: num_kv_heads may be less than num_heads, and KV heads are broadcast (repeated) to match query heads.

The attention computation is standard: scores = Q @ K^T / sqrt(head_dim), softmax over scores, out = softmax_scores @ V. All in bf16 with fp32 softmax accumulation. Correctness tolerance is 0.02 atol/rtol on bf16 outputs. The shapes you have to handle range from small batch/long context (Llama-3 8B decode) to large batch/medium context (server decode), including GQA with 64 heads / 8 kv-heads, non-power-of-2 seq_len, and head_dim=64.

This needs to be a real custom kernel — HIP C++ via torch.utils.cpp_extension.load_inline, Triton on ROCm, or inline GCN assembly, whatever you think fits. Don't reach for vllm.attention, flashinfer, or torch.nn.functional.scaled_dot_product_attention; they're off-limits. Anything you're uncertain about, look up ROCm docs, read library headers, and investigate.

Your flywheel is implement, profile (rocprof, omniperf, torch.profiler — whatever's useful) and time it with benchmark.py, verify correctness by running python check.py and reading the output, then iterate. If python check.py hasn't printed PASS, you're not done. Take as long as you need to actually push the number up.
